JavaScript

O que é JavaScript

JavaScript é uma linguagem de programação amplamente utilizada para criar interatividade em páginas web. Ela permite manipular elementos da página, responder a ações do usuário e comunicar-se com servidores.

O que o JavaScript consegue fazer?

Criar interfaces interativas. Validar formulários. Manipular conteúdo HTML e CSS. Consumir APIs. Desenvolver aplicações web completas. Criar aplicações para servidores com Node.js. Desenvolver aplicativos móveis e desktop com frameworks específicos

javascript funciona apenas no navegador?

Não. Embora tenha sido criado para navegadores, hoje também pode ser executado em servidores, aplicativos desktop, aplicativos móveis e até dispositivos embarcados.

JavaScript é uma linguagem difícil de aprender?

Não. É considerada uma das linguagens mais acessíveis para iniciantes. No entanto, recursos mais avançados podem exigir mais estudo e prática.

Qual a diferença entre JavaScript e Java?

Apesar dos nomes parecidos, são linguagens diferentes. JavaScript é interpretada e muito utilizada para desenvolvimento web. Java é compilada e amplamente utilizada em aplicações corporativas, sistemas Android e back-end.

Phyton

O que é Phyton

Python é uma linguagem de programação de alto nível conhecida por sua sintaxe simples e legível.

O que o Phyton consegue fazer?

Desenvolvimento web. Automação de tarefas. Ciência de dados. Inteligência artificial e aprendizado de máquina. Desenvolvimento de APIs. Criação de scripts e ferramentas.

Phyton funciona apenas no navegador?

Não. Python é executado principalmente em servidores e computadores. Também pode ser utilizado em navegadores por meio de tecnologias específicas, mas esse não é seu uso principal.

Como funciona o esquema de numeração de versões do Python?

O Python utiliza o padrão MAJOR.MINOR.PATCH. Por exemplo:

3.12.0 → versão principal 3, atualização menor 12, correção 0.

Mudanças incompatíveis geralmente ocorrem apenas em versões principais.

O Python é uma boa linguagem para quem está começando na programação agora?

Sim. Sua sintaxe simples e grande quantidade de materiais de estudo fazem do Python uma das melhores opções para iniciantes.

TypeScript

O que é TypeScript

TypeScript é uma linguagem desenvolvida pela Microsoft que adiciona tipagem estática ao JavaScript.

O que o TypeScript consegue fazer?

Tudo o que o JavaScript faz, além de fornecer recursos de tipagem, interfaces, generics e ferramentas que ajudam a reduzir erros em projetos grandes.

TypeScript funciona apenas no navegador?

Não. O código TypeScript é compilado para JavaScript e pode ser executado em qualquer ambiente que execute JavaScript, como navegadores e servidores.

O que é TypeScript e como ele difere do JavaScript?

O TypeScript é um superset (superconjunto) do JavaScript. A principal diferença é que o TypeScript possui tipagem estática, permitindo a verificação de tipos durante a escrita e compilação do código, enquanto o JavaScript tem tipagem dinâmica e só revela erros de tipo em tempo de execução.

Prevenção de erros: Detecta falhas de tipo antes de rodar a aplicação.Refatoração segura: Alterar nomes de variáveis ou funções em grandes bases de código fica mais confiável.Autocompletar inteligente: A IDE consegue sugerir propriedades e métodos com base no tipo conhecido.Documentação viva: As assinaturas de tipo evitam a ambiguidade do que uma função espera receber.

PHP

O que é PHP

PHP é uma linguagem de programação voltada principalmente para desenvolvimento web no lado do servidor.

O que o PHP consegue fazer?

Criar sites dinâmicos. Gerenciar bancos de dados. Desenvolver APIs. Criar sistemas web completos. Processar formulários e autenticação de usuários.

PHP funciona apenas no navegador?

Não. O PHP é executado principalmente no servidor, mas também pode ser utilizado em linha de comando para automação e scripts.

Qual é a principal diferença entre sessões e cookies?

Cookies são armazenados no navegador do usuário. Sessões armazenam dados no servidor e apenas um identificador é mantido no navegador

Quais são os benefícios de usar PHP?

Fácil aprendizado. Grande comunidade. Excelente suporte para hospedagem. Integração simples com bancos de dados. Ampla utilização em sistemas web.

O que são Optionals?

Optionals são um recurso de segurança essencial do Swift. Eles indicam que uma variável ou constante pode conter um valor ou pode ser nula (nil). Para utilizar o valor de um Optionals com segurança, é necessário tratá-lo usando técnicas como Optional Binding (if let ou guard let).

C#

O que é C#

O que a C# consegue fazer?

C# funciona apenas no navegador?

Qual a diferença entre tipos de valor e tipos de referência em C#?

Os dois são variáveis, mas os tipos de valor contêm os próprios dados, mantendo-os na sua alocação de memória. Já os tipos de referência apontam para outro local de memória que possuem os dados reais. O local de armazenagem também é diferente. Os tipos de valor ficam na stack, e os tipos de referência ficam na heap.
